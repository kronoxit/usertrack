чтобы запустить программу в терминале нужно выполнить следуещее:
npm install (если выдаёт ошибку то перед этим выполнить "Set-ExecutionPolicy RemoteSigned -Scope CurrentUser"    +    проверить установленны ли Python(3.10+) и Node.js(22+))
npm run dev
после в терминале появятся ссылки любая из них перекидывает на мой продукт
